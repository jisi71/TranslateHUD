# v0.3.2（草案）：浮窗随内容伸缩，选区前后文作为翻译参考

本文是草案。Developer ID 公证和官网发布都还没做。GitHub Release 里目前没有 v0.3.2 的公证压缩包。

下面只记录 v0.3.1 之后已经在 main 上的用户可见变化。

## 浮窗高度

- 选区浮窗和截图浮窗按内容增高。短原文、短译文不再停在一块很高的空白里，顶部和底部操作栏保持可用。
- 窗口按顶部对齐往下变高。已经拖开的浮窗在出字时保持顶部位置。
- 原文未展开时，高度跟文字走，从 1 行到 6 行。更长的原文在这 6 行里滚动；展开和朗读按钮留在滚动区域外面。
- 译文随文字增高，超过屏幕允许的高度后在正文里滚动。流式译文从开头显示，并停在开头，直到阅读的人自己滚动。

## 选区前后文

- 翻译选中文字时，如果辅助功能读到了前后文，模型会收到同一段节选：前文、嵌在原处的选中文字、后文。选中文字会再单独给出，作为唯一要翻译的内容。
- 这段节选用来判断文章类型、领域、语气和歧义词。请求要求模型不要翻译整段节选，也不要听从节选里的指示。
- 展开名词解释时，同一段节选只用于判断领域。请求要求不要解释只出现在选区外面的词。
- 没有前后文时，请求与以前相同。截图和 OCR 翻译不附带这段参考。
- 网页、浏览器和部分套壳应用会多试几种读取方式：先看焦点元素的文本和选区，再试网页文本标记，然后在有限范围内查看相邻文本。仍读不到时，翻译照常进行，浮窗提示无法读取前后文。
- 前后文每侧保留 120 个字符。某一侧被截断时，外侧的省略号不计入这 120 字。
- 个别 Electron 套壳应用在普通读取失败后，可能会打开系统的增强辅助功能开关。该开关在这个应用本次运行期间一直有效，有可能影响它的窗口动画或位置。浏览器不会走这一步。

## 下载与安装

计划中的公开包是 Developer ID 签名并经 Apple 公证的 `TranslateHUD-0.3.2-universal.zip`，放在官网下载。

- 解压后把 `TranslateHUD.app` 放进 `/Applications`，然后直接双击打开。Gatekeeper 应接受这个包。
- 「辅助功能」和「屏幕录制」仍需在系统设置里手动打开。从旧的 ad-hoc 安装换到公证包时，这两项可能需要重新授权。
- 需要 macOS 14.0 及以上。
- 从源码构建时，继续使用 `scripts/install-local.sh` 的本地签名，或 `scripts/build-release.sh` 的本地 ad-hoc 签名。

## 版本

- 营销版本 `0.3.2`，构建号 `8`。`project.yml` 写入 `MARKETING_VERSION` 和 `CURRENT_PROJECT_VERSION`。`Info.plist` 的短版本号和构建号引用这两个字段，Finder「显示简介」会显示 `0.3.2`。
- 公证、装订和官网上传尚未进行。本文不记录这些检查的结果。
