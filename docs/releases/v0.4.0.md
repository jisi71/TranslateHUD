## 体验翻译

- 没填自己的 API Key，并且接口地址不是本机时，翻译走我们的服务。服务端保存翻译密钥，App 里不放密钥。
- 单次原文最多 500 字（按字素计，一个汉字算一个）。超出时提示：`超出单次翻译上限（体验额度单次最多 500 字）`。这次不扣费。
- 大约每 10 个字扣 ¥0.01，不满 10 个字也扣 ¥0.01。500 字大约扣 ¥0.50。
- 划词翻译仍然边出字边显示。服务需要部署成可流式转发的地址，见 `backend/README.md`。
- 余额用完后，提示去填写自己的 API Key。填好之后，划词、截图、朗读、名词解释都走原来的直接接口，不再扣体验额度。
- 本机模型（地址是 localhost 或 127.0.0.1）即使不填 Key，也继续直接连接，不走体验额度。
