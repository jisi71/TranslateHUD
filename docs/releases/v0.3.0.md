# v0.3.0：全新翻译浮窗与连接自动恢复

TranslateHUD 更新了选中文字翻译和截图翻译的界面。原文、翻译状态与译文集中展示，语言选择和常用操作直接放在浮窗中。

截图来自原生 SwiftUI 界面，使用示例文案。

## 新功能与界面改进

- 统一深色浮窗，重新整理顶部语言菜单、置顶与关闭按钮，以及底部 API 操作栏。
- 在浮窗中切换目标语言后立即重新翻译，支持复制译文、朗读原文与译文、刷新及进入 API 设置。
- 支持展开选中文字前后的文本，并突出选中内容；来源应用未提供前后文时显示提示。
- 截图翻译可按需展开原始截图，保留原文与译文查看、朗读和术语解释。
- 长文本在内容区滚动，顶部和底部操作栏保持可用；置顶后的选区浮窗不会因点击其他窗口而关闭。

## 翻译可靠性

- 针对尚未输出译文时发生的特定 TLS 数据校验中断，自动创建新会话并重试一次，界面显示“重试中”。保留系统代理、TLS 默认设置和证书校验。
- 网络恢复和质量校验共用每轮最多两次请求额度，保留取消、空闲超时和总耗时限制。
- 完善空译文、缺失或重复索引、输出截断和流式响应提前结束的校验，避免把不完整结果当作成功。
- 减少网址、路径和带中文释义的专名引起的误报；改善接口地址拼接与 HTTP 错误提示。
- 选区诊断记录字符数，不再记录选中文字原文；HTTP 错误提示不展示服务响应正文。

## 下载与安装

下载附件 `TranslateHUD-0.3.0-universal.zip`，解压后将 `TranslateHUD.app` 放入 `/Applications`。

- 系统要求为 macOS 14.0 及以上。
- 同一安装包包含 Apple Silicon 与 Intel 架构。
- 公开安装包使用 ad-hoc 签名，未经过 Apple 公证；首次打开如被系统拦截，请右键应用并选择“打开”。
- 升级后 macOS 可能要求重新确认辅助功能与屏幕录制权限。本机源码安装可继续使用 `scripts/install-local.sh` 沿用稳定本地签名。
