TranslateHUD 隐私政策

更新日期：2026-10-26
生效日期：2026-10-26

TranslateHUD（以下简称「本应用」）由齐亚浩（以下简称「我们」）以个人身份运营。我们重视你的个人信息保护，本政策说明我们如何收集、使用、存储和保护相关信息。本应用主要面向成年人。

你同意本政策，不代表我们会处理文中列出的全部信息。我们只会在你使用相应功能时，按最小必要原则处理相关信息。

一、我们收集哪些信息

1. 手机号与登录态
当你选择短信登录时，我们收集你的手机号码，用于发送验证码、注册/登录、找回账号，以及与账号相关的必要通知。登录成功后，我们会保存登录状态（如登录凭证），以便你保持登录。
若你拒绝提供手机号，仍可使用不依赖账号的功能，但无法使用登录、体验余额、邀请码等账号能力。

2. 体验账本
当你领取邀请码体验余额、或通过官方体验通道翻译并扣费时，我们记录与记账相关的信息，例如余额变动、扣减的 TOKEN/用量、时间等，用于完成计费、对账和防作弊。

3. 翻译相关内容（官方体验通道）
当你使用官方体验通道时，为完成翻译，我们会将你提交的待译文本、截图经 OCR 识别后的文字等，发送至腾讯云开发（上海）个人版等云服务进行处理，并据此扣减体验余额。我们不会把这些内容用于与提供翻译服务无关的目的，也不会将其出售。

4. 自填 API Key
若你自行填写 API Key：API Key 仅保存在你的本地设备，不会上传到我们的服务器。你的输入由你直接发往你指定的第三方服务，由其独立处理并直接返回结果；此过程我们不中转你的正文内容。

5. 意见反馈
当你提交反馈时，我们会收集你填写的标题、正文，以及你主动上传的配图，用于处理问题与改进产品。反馈内容保存在腾讯云开发等云服务中。

6. 设备与日志
为保障服务安全与稳定，我们可能收集必要的设备信息与操作日志（例如设备型号、系统版本、应用版本、崩溃日志、大致操作时间）。我们不会据此识别你的精确位置。

我们不会主动收集你的身份证号、通讯录、精确地理位置等信息。如未来新增能力涉及更多个人信息，我们会另行说明并在需要时征得你的同意。

二、我们如何使用信息

我们出于以下目的使用上述信息：
1. 提供注册登录、翻译、OCR、体验余额与邀请码等核心功能；
2. 保障账号与交易安全、防范欺诈与滥用；
3. 处理你的反馈、进行客户支持；
4. 改进产品体验与排查故障；
5. 遵守法律法规、配合监管与司法机关的合法要求。

我们不会将你的翻译原文用于训练我们自有的通用大模型。若未来有此类用途，会事先明确告知并征得你的单独同意。

三、委托处理、共享、转让与公开披露

1. 委托处理
为实现登录短信、云存储、翻译中转与记账等功能，我们委托腾讯云计算等相关服务商处理必要数据。我们会要求其按合同约定保护数据安全，仅在委托范围内处理。
主要涉及：腾讯云开发（上海）个人版等（短信/云函数/数据库等，以实际开通为准）。

2. 共享
我们不会向其他第三方出售你的个人信息。除本政策说明的委托处理、或法律法规另有规定外，不会擅自与第三方共享。

3. 转让
如发生合并、收购、资产转让等，我们可能转移个人信息，并要求新的持有方继续受本政策约束，或重新征求你的同意。

4. 公开披露
我们不会公开披露你的个人信息，除非获得你的单独同意，或法律要求必须披露。

5. 依法可不经同意的情形
包括但不限于：为订立/履行合同所必需、履行法定义务所必需、应对突发公共卫生事件或紧急情况下保护生命财产安全所必需、在合理范围内处理你自行公开的信息，以及法律、行政法规规定的其他情形。

四、存储地点与期限

1. 我们在中华人民共和国境内收集和产生的个人信息，存储在境内。
2. 我们仅在实现目的所必要的最短期限内保留。例如：账号存续期间保留手机号与账本记录；你注销账号后，我们将删除或匿名化相关信息，但法律法规要求保留的除外。
3. 反馈内容在处理完毕后，按内部规则在合理期限内删除或匿名化。

五、信息安全

我们采取合理的技术与管理措施保护个人信息，例如访问控制、传输与存储加密等，并限制员工访问权限。
请注意：任何安全措施都无法做到百分之百。如发生个人信息安全事件，我们将按法律要求及时告知你，并采取补救措施。

六、你的权利

在符合法律规定的前提下，你有权：
1. 查阅、复制你的个人信息；
2. 更正、补充不准确或不完整的信息；
3. 删除个人信息（在法定情形下）；
4. 撤回同意（撤回不影响撤回前基于同意的处理）；
5. 注销账号；
6. 获取个人信息副本，或在符合条件时请求转移。

你可通过本应用内反馈，或发送邮件至 translatehud@agent.qq.com 提出请求。我们将在核实身份后，于十五（15）日内或法律规定的期限内答复。

注销账号后，我们将停止为你提供账号相关服务，并对个人信息做删除或匿名化处理（法律要求保留的除外）。体验余额等权益可能随之失效。

七、未成年人保护

本应用主要面向成年人。若你未满 18 周岁，请在监护人指导下阅读本政策并使用本应用。
若你是未满 14 周岁儿童的监护人，请在同意儿童使用前仔细阅读本政策。我们原则上不主动收集儿童个人信息；如误收集，经监护人请求或我们发现后，将尽快删除。

八、政策更新

我们可能适时修订本政策。更新后会在应用内公布，并注明生效日期。若处理目的、方式或处理的个人信息种类发生重大变化，我们将重新取得你的同意。
