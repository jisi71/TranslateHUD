# 用户协议和隐私政策

应用内「帮助」打开的就是下面两个文件：

- `user-agreement.md`：用户协议
- `privacy-policy.md`：隐私政策

设置里未登录时，「登录即表示已阅读」旁边的链接打开的也是这两个文件。应用打包时会把它们放进 App，按文件名读取（`user-agreement.md`、`privacy-policy.md`）。改完文字后需要重新编译安装，已经装上的旧 App 不会自己变。

这两份是法务给的正文，应用里按页面展示，不要再标成「草案」。带【】的位置还是空的，请 Yahao 填写后再发布，不要临时编一个公司名、邮箱或地址：

- 【更新日期】
- 【生效日期】
- 【运营主体全称】
- 【运营主体住所地】（只在用户协议里）
- 【联系邮箱】
- 【邮寄地址】

【联系邮箱】只是占位。帮助里的问题反馈仍然没有邮箱栏，也不会发邮件，也不要在应用里写成 `mailto:`。官网地址还没有，不要补 URL。

隐私政策「一、6. 设备与日志」先保留。法务说只有在确认完全不收集设备信息和日志时才删这一条。括号里的说明也先留着，等 Yahao 核对过再决定要不要删掉这半句。不要为了凑这条去加统计或崩溃收集 SDK。

这份 README 只给开发看，不会在「帮助」里打开。
