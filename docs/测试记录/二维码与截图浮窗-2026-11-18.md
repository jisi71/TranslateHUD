# 二维码共用浮窗与截图等待状态

2026-11-17 至 18 日，基于 main `5d1a5f9924082a0ab7427f8fa41772dca01e682e`，本地分支 `codex/screenshot-qr-panel-20261117`。

## 已实现

- 移除单独的二维码窗口。二维码内容在翻译浮窗的译文区域按普通文本显示；仅二维码截图的原文留空。共用复制、朗读、截图预览和置顶操作，HTTP/HTTPS 链接仍需明确点击才打开。
- 混合截图在同一个窗口保留识别原文、译文和二维码内容。二维码区域继续在 OCR 前遮罩，二维码载荷不进入翻译计划、模型或字数计算；纯二维码结果不准备翻译会话，不要求翻译账号。
- 框选完成后先显示“正在识别截图…”，再进行二维码、普通 OCR 和表格识别，在原窗口更新结果。识别期间不创建空的原文编辑器；关闭窗口后忽略迟到的识别结果，不再开始翻译。
- 截图浮窗保持 `.floating` 层级，避免普通窗口的激活排序把它遮住。置顶只改变点外关闭规则，不再在取消置顶时降为普通窗口；划词浮窗的取消置顶行为保持一致。保留原来的 NSWindow 和拖拽实现。

相关实现为 `ScreenshotFlow.swift`、`ScreenshotSourceState.swift`、`ScreenshotQRCode.swift`、`FloatingScreenshotWindow.swift`、`FloatingTranslationPopover.swift`、`TranslationPanel.swift` 和 `TranslationProgress.swift`。未改 OCR、表格判定、合并单元格或文字校正算法。
