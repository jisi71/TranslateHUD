TranslateHUD 隐私政策

更新日期：2026-11-24
生效日期：本版本公布之日

齐亚浩（个人）（以下简称「我们」）运营 TranslateHUD（以下简称「本应用」）。我们重视你的个人信息保护，本政策说明我们如何收集、使用、存储和保护相关信息。本应用主要面向成年人。

你同意本政策，不代表我们会处理文中列出的全部信息。我们只会在你使用相应功能时，按最小必要原则处理相关信息。

一、我们收集哪些信息

1. 手机号、邮箱与登录态
当你选择短信或邮箱验证码登录时，我们收集你提供的手机号码或邮箱地址，用于发送验证码、注册/登录、找回账号，以及与账号相关的必要通知。登录成功后，我们会保存登录状态（如登录凭证），以便你保持登录。
若你不提供手机号或邮箱，仍可使用不依赖账号的功能。手机号或邮箱登录后可使用每日免费额度。符合条件的中国大陆手机号账号可凭邀请码领取体验余额。

2. 体验账本
当你领取邀请码体验余额、或通过官方体验通道翻译并扣费时，我们记录与记账相关的信息，例如余额变动、扣减的 TOKEN/用量、时间等，用于完成计费、对账和防作弊。

3. 翻译相关内容（官方体验通道）
使用官方每日免费额度或邀请码体验余额时，请求经腾讯云开发（上海）转发到当前的上游模型服务商 DeepSeek（深度求索）。为完成翻译或名词解释，转发待译文本及该请求所需的目标语言、参考上下文等信息。截图先在 Mac 上识别文字，正常翻译流程只发送识别出的文字，不上传整张截图。翻译原文和译文不写入使用账本或失败诊断日志。你主动提交的反馈按下述规则处理。

4. 自填 API Key
若你自行填写 API Key，密钥保存在本机钥匙串。应用把翻译正文直接发送给你选择的模型服务商，由该服务商按其条款和隐私政策处理。连接本机 Ollama 时，应用把请求发送到你配置的本地地址。

5. 意见反馈
当你提交反馈时，我们会收集你填写的标题、正文，以及你主动上传的配图，用于处理问题与改进产品。反馈内容保存在腾讯云开发等云服务中。
翻译质量反馈由你点击反馈并在预览中确认后提交，包含当次原文、模型候选译文、显示内容、目标语言、质量检查标记、应用版本、入口、模型名称和提交账号标识。不包含截图、API Key、登录凭证、其他剪贴板内容或后续编辑；不会自动上传或自动重试。此独立功能用于排查漏译并改进翻译体验。

6. 设备与日志
为保障服务安全与稳定，我们可能收集必要的设备信息与操作日志（例如设备型号、系统版本、应用版本、崩溃日志、大致操作时间）。我们不会据此识别你的精确位置。若某版本实际上未收集上述信息，则以实际行为为准，我们不会超范围收集。

我们不会主动收集你的身份证号、通讯录、精确地理位置等信息。如未来新增能力涉及更多个人信息，我们会另行说明并在需要时征得你的同意。

二、我们如何使用信息

我们出于以下目的使用上述信息：
1. 提供注册登录、翻译、OCR、体验余额与邀请码等核心功能；
2. 保障账号与交易安全、防范欺诈与滥用；
3. 处理你的反馈、进行客户支持；
4. 改进产品体验与排查故障；
5. 遵守法律法规、配合监管与司法机关的合法要求。

我们不会将你的翻译原文用于训练我们自有的通用大模型。若未来有此类用途，会事先明确告知并征得你的单独同意。

三、委托处理、共享、转让与公开披露

1. 委托处理
腾讯云开发（上海）处理验证码发送和校验、登录、翻译中转、云存储和记账所需的数据。DeepSeek 是官方翻译服务的上游模型服务商，处理翻译及名词解释请求所需的内容。

2. 共享
我们不会向其他第三方出售你的个人信息。除本政策说明的委托处理、或法律法规另有规定外，不会擅自与第三方共享。

3. 转让
如发生合并、收购、资产转让等，我们可能转移个人信息，并要求新的持有方继续受本政策约束，或重新征求你的同意。

4. 公开披露
我们不会公开披露你的个人信息，除非获得你的单独同意，或法律要求必须披露。

5. 依法可不经同意的情形
包括但不限于：为订立/履行合同所必需、履行法定义务所必需、应对突发公共卫生事件或紧急情况下保护生命财产安全所必需、在合理范围内处理你自行公开的信息，以及法律、行政法规规定的其他情形。

四、存储地点与期限

1. 我们用于账号和额度管理的云端数据存储在腾讯云开发上海环境。手机号或邮箱在账号存续期间用于登录及管理额度。余额、扣减用量和时间等账本记录按计费、对账、防滥用和法定需要保留。
2. 腾讯云开发为发送和校验登录验证码作短期处理。登录验证码有效期为 10 分钟。翻译账本不保存验证码。
3. 一般意见反馈在处理完毕后，按内部规则在合理期限内删除或匿名化。翻译质量反馈的原文、译文及整条记录保留 30 天，到期后由每小时运行的清理任务删除。清理可能因执行周期或待处理数量而延后。

五、信息安全

我们采取合理的技术与管理措施保护个人信息，例如访问控制、传输与存储加密等，并限制访问权限。
请注意：任何安全措施都无法做到百分之百。如发生个人信息安全事件，我们将按法律要求及时告知你，并采取补救措施。

六、你的权利

在符合法律规定的前提下，你有权：
1. 查阅、复制你的个人信息；
2. 更正、补充不准确或不完整的信息；
3. 删除个人信息（在法定情形下）；
4. 撤回同意（撤回不影响撤回前基于同意的处理）；
5. 注销账号；
6. 获取个人信息副本，或在符合条件时请求转移。

注销账号或删除个人信息目前由人工受理。请发送邮件至 translatehud@agent.qq.com，注明与请求相关的账号和希望处理的数据。请勿发送验证码、密码或 API Key。我们将在核实身份后，于十五（15）日内或法律规定的期限内答复。

注销账号后，我们将停止为你提供账号相关服务，并对个人信息做删除或匿名化处理（法律要求保留的除外）。体验余额等权益可能随之失效。

七、未成年人保护

本应用主要面向成年人。若你未满 18 周岁，请在监护人指导下阅读本政策并使用本应用。
若你是未满 14 周岁儿童的监护人，请在同意儿童使用前仔细阅读本政策。我们原则上不主动收集儿童个人信息；如误收集，经监护人请求或我们发现后，将尽快删除。

八、政策更新

我们可能适时修订本政策。更新后会在官网或应用内公布，并注明生效日期。若处理目的、方式或处理的个人信息种类发生重大变化，我们将重新取得你的同意。
