# v0.3.1：统一错误提示与完整处理建议

本次更新统一了翻译、名词解释、截图和选区读取的错误提示。常见问题会说明原因和下一步操作，未知原因保留明确的不确定性说明。

## 错误提示优化

- HTTP 402 明确提示“API 账户余额不足”，引导检查服务商平台的余额。
- 鉴权、访问权限、接口或模型不存在、参数不兼容、输入过长、网关与服务端异常分别提供对应建议。
- 根据已知 `error.code` 或 `error.type` 区分 HTTP 429 的限流和额度不足；无法确定时不会直接判定余额耗尽。
- 对 HTTP 200 响应或流式事件中携带的服务错误进行识别，额度错误不再作为译文格式错误重试。
- 兼容正常响应中的 `error: null`，避免把有效译文或名词解释误报为服务错误。
- 断网、DNS、服务器连接、TLS 与证书错误使用中文提示，保留原有证书校验和请求额度。
- 超时区分请求等待、连续无新译文和总耗时超限，并显示实际时间限制。
- 截图、OCR 和剪贴板读取失败提供可执行的处理步骤，服务响应正文不再出现在名词解释提示中。

## 显示与界面等待

- 设置页和名词解释完整显示长错误提示；通知浮窗根据内容调整高度，并留出阅读时间。
- API Key 按需从原钥匙串记录读取，普通浮窗渲染与配置校验不再触发凭据读取。原有保存位置保持不变。

## 下载与安装

下载 `TranslateHUD-0.3.1-universal.zip`，解压后将 `TranslateHUD.app` 放入 `/Applications`。

- 需要 macOS 14.0 及以上；同一安装包包含 Apple Silicon 与 Intel 架构。
- 公开包使用 ad-hoc 签名，未经过 Apple 公证；首次打开如被系统拦截，请右键应用并选择“打开”。
- 升级后 macOS 可能要求重新确认辅助功能与屏幕录制权限。本机源码安装可使用 `scripts/install-local.sh` 沿用稳定本地签名。
