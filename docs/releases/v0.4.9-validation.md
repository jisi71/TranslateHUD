# TranslateHUD 0.4.9 发布验收

2026-11-18 发布 0.4.9，构建 19。[源码 PR #75](https://github.com/jisi71/TranslateHUD/pull/75) 已合并到 `4db27c6f4aa13a1111fc49b02566380251226200`，发布标签指向同一提交。[GitHub 正式版](https://github.com/jisi71/TranslateHUD/releases/tag/v0.4.9)

## 客户端与后端

- 客户端全量 777 项中 762 项通过、15 项跳过、0 项失败。17 项浮窗测试通过。原文区布局标识已修正，保留了原有的高度、宽度和锚点断言。
- 44 张表格截图重新识别，导出结果与上一轮逐张一致。50 张普通文字样本尚未提供。Intel 和旧版 macOS 实机覆盖未验证。
- 离线对照验证了编号版本启动预加载、额度结算、鉴权和划词 SSE 响应。官方体验截图和划词入口均绑定 `trial-stream` 版本 1，1 个预置实例已就绪。两条路由的未登录空请求均被拒绝。
- 本机截图测试构建 18.5 实际命中预置实例。实例启动预加载耗时 718 毫秒。同一张截图从采集到译文解析完成的两次计时约为 11.23 秒和 3.27 秒。正式划词的验收覆盖路由读回、网关鉴权和后端 SSE 对照。
