# 用户协议和隐私政策

应用内「帮助」打开的就是下面两个文件：

- `user-agreement.md`：用户协议
- `privacy-policy.md`：隐私政策

设置里未登录时，「登录即表示已阅读」旁边的链接打开的也是这两个文件。应用打包时会把它们放进 App，按文件名读取（`user-agreement.md`、`privacy-policy.md`）。改完文字后需要重新编译安装，已经装上的旧 App 不会自己变。

这两份按正式产品页面来写，应用里不要出现「草案」字样。法务审阅还没有做。Yahao 或法务可以直接改这两个 Markdown。审阅意见写进正文即可，不要在用户能看到的页面上标成草稿。

改的时候请保持和现在的产品一致：

- 没有官网地址。地址还没定，不要自己补一个 URL。
- 没有反馈邮箱，也不要写 `mailto:`。问题反馈只走应用内「帮助 → 问题反馈」，存到云开发集合 `trial_feedback`。
- 正文里没有写运营主体的公司名称。如果法务要求补上，直接改这两个文件。
- 更新日期写在每份正文开头。改过内容就改这个日期。

这份 README 只给开发看，不会在「帮助」里打开。
