## 体验翻译

- 没填自己的 API Key，并且接口地址不是本机时，翻译走我们的服务。服务端保存翻译密钥，App 里不放密钥。
- 单次原文最多 500 字（按字素计，一个汉字算一个）。超出时提示：`超出单次翻译上限（体验额度单次最多 500 字）`。这次不扣费。
- 成功的翻译按上游报告的 token 费用扣体验额度（输入、输出分开计价）。账本精确到微元（¥0.000001），不再把不足 1 分的费用进成 ¥0.01。界面只显示体验余额，金额显示到分，四舍五入，不满半分显示为 ¥0.00。不显示本次花费。0.4.0 最初按大约每 10 个字 ¥0.01 扣，这条已不再使用。
- 划词翻译仍然边出字边显示。服务需要部署成可流式转发的地址，见 `backend/README.md`。
- 余额用完后，提示去填写自己的 API Key。填好之后，划词、截图、朗读、名词解释都走原来的直接接口，不再扣体验额度。
- 本机模型（地址是 localhost 或 127.0.0.1）即使不填 Key，也继续直接连接，不走体验额度。

## API Key

- Key 保存在系统钥匙串里。App 记住有没有存过：没存过，或已经清空，启动时不去读钥匙串。
- 第一次保存时，系统可能会问一次是否允许 TranslateHUD 读取。点「始终允许」之后，以后重新打开会直接读出这串 Key。
- 把输入框清空会删掉这条钥匙串记录。体验账号退出登录也会删掉登录状态。
