# 0.4.7 发布验收记录

当前状态：0.4.7 / 构建 17 已完成签名、公证与隔离升级验收，并已公开发布；公网下载、正式安装路径的软件内升级及官网同步结果将分别记录。

## 范围与审查

本版包含浮窗边缘缩放、原文分隔线与标题移窗分离、固定完整译文视口，以及相邻富文本片段误换行修复。既有未提交的其他剪贴板和渲染工作未并入本版；最新 main 的官网表格展示修改保留。

发布前代码复核检查了窗口事件路由、屏幕与最小高度边界、手动尺寸与自动适配冲突、译文视口占用空白、相邻行内节点与真实块边界。此前失败的布局和人工录屏结果均保留，没有用自动测试结果覆盖人工失败。

- 最终发布源码 `2d179157de69ffd7eefa905efe6768b13c4e739e`：647 项自动检查中 641 通过、6 个可选样本/导出入口跳过、0 失败。版本为 0.4.7 / 构建 17，已合入 main 的官网表格改动。
- 已有 44 张表格图片全部重新执行并核验哈希，三种识别输出均与本机 16.9 结果一致，混合识别输出也与正式 0.4.6 一致；42 张生成表格，不等于 42 张文字和结构均正确。固定的 113 个确认格全部映射，混合差错仍为 52 / 1,814（2.87%）。
