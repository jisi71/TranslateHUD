# TranslateHUD 0.4.8

- 改进漏译检查；完整译文可能漏译时仍显示结果，并在结尾附灰色提示和反馈按钮。
- 登录后可预览并主动提交当次原文、候选译文及质量诊断，帮助排查翻译问题。不会自动上传，质量反馈保留 30 天后定时清理。
- 截图支持本机识别二维码，查看、复制内容或主动打开网页链接；二维码内容不会自动送去翻译。
- 对符合条件的倾斜截图进行本机校正，不确定时保留原图识别流程。
- 浮窗原文和译文可直接放置光标编辑；修改原文后手动重新翻译。改进 Markdown 标题、列表、引用和表格的转换、显示与编辑。
- 修复可编辑译文超出视口时，拖动原文分隔线导致布局失稳的问题。

复杂截图仍可能出现错字、漏字或合并单元格偏差，请对照原图检查。可编辑文字与单元格不代表支持随意增删表格行列。

首次安装使用 DMG，已有正式版用户可在软件内检查更新。支持 macOS 14 及以上，同一安装包包含 Apple Silicon 与 Intel 架构。
