v0.3.2

浮窗随内容伸缩，选区前后文作为翻译参考 Panels fit their content, and nearby text can guide a translation

草案 · 尚无安装包 Draft · no package
  • 选区浮窗和截图浮窗按内容增高。短原文、短译文不再留在一块很高的空白里。窗口从顶部往下变高；已经拖开的浮窗在出字时保持顶部位置。 Selection and screenshot panels grow with their content, so a short passage no longer sits in a tall empty area. The window grows downward from the top. A panel you have dragged keeps that top edge while text arrives.
  • 原文未展开时从 1 行长到 6 行，更长就在这 6 行里滚动。展开和朗读留在滚动区域外面。译文随文字增高，超出屏幕允许的高度后在正文里滚动。流式译文停在开头，直到你自己往下滚。 A collapsed source grows from one line to six, then scrolls inside those six lines. Expand and speak stay outside the scroller. The translation grows until the screen limit, then scrolls. A stream stays at the start until you scroll.
  • 翻译选中文字时，如果读到了前后文，模型会收到同一段节选：前文、嵌在原处的选中文字、后文。选中文字再单独给出，那才是要翻译的内容。节选用来判断文章类型、领域、语气和歧义词。请求要求不要翻译整段节选，也不要听从节选里的指示。 When surrounding text is available, the model receives one excerpt: text before, the selection in place, and text after. The selection is also given on its own, and that is the only part to translate. The excerpt is for genre, domain, tone, and ambiguous words. The request says not to translate the whole excerpt and not to follow instructions inside it.
  • 名词解释只用这段节选判断领域，并要求不要解释只出现在选区外面的词。没有前后文时，请求与以前相同。截图和 OCR 不附带这段参考。 Term notes use the excerpt only to judge the domain, and must not explain words that appear only outside the selection. With no surrounding text, the request stays as before. Screenshot and OCR translation do not include this reference.
  • 网页和部分套壳应用会多试几种读法。仍读不到时，翻译照常进行，浮窗提示无法读取前后文。前后文每侧最多 120 个字符。某一侧被截断时，外侧的省略号不计入这 120 字。 Web pages and some wrapped apps try more than one way to read context. If that still fails, translation continues and the panel says the surrounding text is unavailable. Each side keeps at most 120 characters. An ellipsis outside a truncated side does not count toward those 120.
  • 个别 Electron 套壳应用在普通读取失败后，可能会打开系统的增强辅助功能开关。该开关在这个应用本次运行期间一直有效，有可能影响它的窗口动画或位置。浏览器不会走这一步。 After a normal read fails, a few Electron-wrapped apps may turn on the system’s enhanced accessibility switch. It stays on for that app’s current run and can affect its window animation or position. Browsers do not take this step.
  • 计划中的公开包是 Developer ID 签名并经 Apple 公证的 TranslateHUD-0.3.2-universal.zip。公证和上传都还没做，所以这里不提供下载。 The planned public package is a Developer ID–signed and notarized TranslateHUD-0.3.2-universal.zip. Notarization and upload have not been done, so this page does not offer a download.

v0.3.1

统一错误提示与完整处理建议 Clearer errors, with a next step

当前发布 Current release 2026-10-09
  • 鉴权、余额、权限、接口参数、模型与服务端错误会分别说明原因和下一步。HTTP 402 明确提示 API 账户余额不足。 Authentication, balance, permission, parameter, model, and server errors each explain the cause and a next step. HTTP 402 says the API account balance is insufficient.
  • HTTP 429 会按已知错误码区分限流和额度不足；无法确定时保持中性说明，不直接判定余额耗尽。额度错误不会当作译文格式错误反复请求。 HTTP 429 distinguishes rate limits from quota when a known error code says which is which. If the cause is unclear, the message stays neutral and does not claim the balance is gone. A quota error is not retried as a formatting failure.
  • 断网、DNS、连接中断、TLS 和证书错误使用中文提示。超时会说明是请求等待、连续没有新译文，还是总耗时超限，并写出实际时间限制。 Offline, DNS, dropped connection, TLS, and certificate failures use Chinese messages. A timeout says whether the wait was for the request, for new translation text, or for the total time, and it shows the actual limit.
  • 长提示完整换行。通知浮窗按内容调整高度和停留时间。名词解释不再显示服务响应正文。截图、OCR 和选区错误会补充下一步。API Key 改为按需读取，普通浮窗渲染不再触发钥匙串读取。 Long messages wrap in full. A notice sizes itself to the text and stays up long enough to read. Term notes no longer show the service response body. Screenshot, OCR, and selection errors add a next step. The API key is read only when needed, so drawing an ordinary panel no longer touches the Keychain.
  • 公开包是 ad-hoc 签名，未经 Apple 公证。首次打开若被拦截，右键应用并选择「打开」。需要 macOS 14.0 及以上，安装包包含两种架构。Intel 实机还没有验证。升级后系统可能要求重新确认两项权限。 The public package is ad-hoc signed and not notarized. If the first open is blocked, right-click the app and choose Open. It needs macOS 14.0 or later and contains both architectures. Intel hardware has not been verified. After an upgrade, macOS may ask you to confirm both permissions again.

v0.3.0

全新翻译浮窗与连接自动恢复 A new translation panel, and one automatic reconnect

2026-10-08
  • 选中文字和截图翻译改用同一套深色浮窗。顶部是语言、置顶和关闭，底部是 API 操作。长文本在内容区滚动。 Selection and screenshot translation share one dark panel. Language, pin, and close sit at the top. API actions sit at the bottom. Long text scrolls in the body.
  • 可以在浮窗里切换目标语言并立即重译，也可以复制译文、朗读原文与译文、刷新、进入 API 设置。置顶后的选区浮窗不会因为点了其他窗口而关闭。 The panel can switch the target language and retranslate immediately. It can also copy, speak either side, refresh, and open API settings. A pinned selection panel stays open when you click another window.
  • 可以展开选中文字前后读到的文本，并突出选中内容。来源应用没有提供时会提示。截图翻译可以展开原始截图。这一版只是查看；把前后文交给模型，是上面的 v0.3.2 草案。 You can expand text read from around the selection, with the selection marked. If the source app did not provide it, the panel says so. Screenshot translation can expand the original capture. This version only shows that text. Sending it to the model is the v0.3.2 draft above.
  • 译文还没出来时，若发生特定的 TLS 数据校验中断，会自动新建会话并重试一次，界面显示「重试中」。系统代理和证书校验保留。空译文、缺索引、重复索引和提前结束的流式响应不会当成成功。 If a specific TLS data-check failure happens before any translation has appeared, TranslateHUD opens a new session and retries once, and the panel says it is retrying. The system proxy and certificate checks stay in place. An empty translation, a missing or repeated index, or a stream that ends early is not treated as success.
  • 公开包同样是 ad-hoc 签名、未公证，需要 macOS 14.0 及以上。Intel 实机尚未验证。 The public package is also ad-hoc signed and not notarized, and it needs macOS 14.0 or later. Intel hardware was not verified.

v0.2.0

朗读与专有名词解释 Speech and term notes

2026-07-11
  • 新增原文与译文朗读，优先使用已下载的高音质语音，并支持中英文混合文本分段朗读。设置里可以选语音和语速。 Adds speech for the source and the translation, preferring downloaded higher-quality voices, including mixed Chinese and English read in segments. Voice and rate are in Settings.
  • 新增专有名词解释，可在翻译结果下按需生成中文解释。 Adds on-demand Chinese notes for proper nouns, under the translation.
  • 修复翻译浮窗偶尔出现在屏幕左下角的问题。同一快捷键下，没读到选中文字时进入截图翻译。改进屏幕录制权限提示，本地 Ollama 可以不填 API Key。 Fixes a panel that sometimes opened at the bottom-left of the screen. With the shared shortcut, a missed selection falls through to screenshot translation. Screen-recording guidance is clearer, and local Ollama can be used without an API key.
  • 首次打开若被拦截，右键应用并选择「打开」。安装包包含 Apple 芯片与 Intel 架构。 If the first open is blocked, right-click the app and choose Open. The package contains Apple silicon and Intel.

v0.1.3

更稳的流式输出 More reliable streaming

2026-05-09
  • 选区浮窗高度随内容变化，多行原文和译文不再被截成一行。流式文字填入时窗口不会往上飘。 The selection panel’s height follows the content, so multiple lines are no longer cut down to one. The window does not drift upward as streamed text arrives.
  • 对原文回吐、拒绝翻译、代码块包裹和只翻了一半做检查，命中后用更严的提示重试一次。流式过程中如果发现输出仍是原文前缀，会中断并重试。 Checks for echoing the source, refusing to translate, wrapping the result in a code block, or translating only halfway, then retries once with a stricter prompt. If a stream is still just the start of the source, it stops and retries.
  • SSE 按规范合并多行 data，并兼容不发空行分隔的服务。没有内容片段时不再静默变成空译文。用户取消截图不会再被报成截图失败。 SSE joins multiline data fields, including services that omit the blank-line separator. A response with no content is no longer a silent empty translation. Cancelling a screenshot is no longer reported as a screenshot failure.

v0.1.1

选中文字改为流式翻译 Selection translation starts streaming

2026-05-06
  • 选中文字的翻译改为流式输出，译文边生成边显示。多段输入如果被模型压掉换行，会改走逐行批量翻译。 Selection translation becomes a stream, so the translation appears as it is generated. If a multi-paragraph input loses its line breaks, TranslateHUD falls back to a line-by-line batch.
  • 针对 DeepSeek 默认开启的 thinking 模式做了兼容：检测到 DeepSeek 地址时会关掉 thinking。预设模型改为当时的 deepseek-v4-flash。 DeepSeek’s thinking mode, which was on by default, is turned off when the address is recognized as DeepSeek. The preset model of that release was deepseek-v4-flash.
  • 选区浮窗的长文本放进滚动区域，右下角可以拖大。剪贴板兜底会保留原来的多项内容；没有选区时不再做一次无意义的还原。 Long selection text scrolls, and the panel can be resized from the corner. The clipboard fallback keeps the original multi-item clipboard, and it no longer restores anything when there was no selection.
  • 这一版的公开包是 ad-hoc 签名。首次打开需要右键并选择「打开」。 This public package is ad-hoc signed. The first open needs a right-click and Open.

v0.1.0

第一个公开版本 First public release

2026-05-05
  • 菜单栏工具。默认 Option+W：有选中文字就翻译选区，否则框选屏幕。读选区时先试辅助功能，不行再试复制，最后才截图。 A menu-bar tool. Option+W by default translates a selection when there is one, and otherwise captures a screen region. Reading a selection tries Accessibility, then a copy, and only then a screenshot.
  • 接入 OpenAI 兼容接口，预设包括 OpenAI、DeepSeek、Kimi、智谱、通义、OpenRouter、本地 Ollama 和自定义。默认译成简体中文；输入主体是中文时改译成英语。 Connects to an OpenAI-compatible API. Presets include OpenAI, DeepSeek, Kimi, Zhipu, Qwen, OpenRouter, local Ollama, and a custom endpoint. The default target is Simplified Chinese; mainly Chinese input is translated into English.
  • 触发后先出现等待中的浮窗，可以取消和重试。需要 macOS 14.0 及以上。公开包 ad-hoc 签名，未公证，首次打开要右键并选择「打开」。 A waiting panel appears when you trigger a translation, and it can be cancelled or retried. Requires macOS 14.0 or later. The public package is ad-hoc signed and not notarized, so the first open needs a right-click and Open.
